\section{Conclusion}
We present a framework for learning robot control policies on granular terrain that combines moving-patch MPM with Particle NeRD.
The moving terrain patch restricts material updates to the region surrounding the robot and its interacting objects, while particle caching restores terrain deformation when the robot revisits a region.
Particle NeRD further accelerates material updates within a restricted material-parameter range.
